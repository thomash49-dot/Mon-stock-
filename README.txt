MON STOCK — application web

Fichiers :
- index.html : application
- manifest.json : installation comme web-app
- service-worker.js : fonctionnement hors connexion lorsqu'elle est hébergée en HTTPS

Utilisation immédiate :
1. Ouvrir index.html dans un navigateur moderne.
2. Les données sont sauvegardées localement sur l'appareil grâce à localStorage.

Pour l'installer sur iPhone comme une application :
1. Héberger le dossier sur un site HTTPS.
2. Ouvrir l'adresse dans Safari.
3. Appuyer sur Partager > Ajouter à l'écran d'accueil.

Fonctions incluses :
- ajout, modification et suppression de produits
- catégories
- quantité actuelle, seuil d'alerte et stock idéal
- liste automatique de réapprovisionnement
- boutons +1 / -1
- recherche
- filtre par catégorie
- export CSV
- sauvegarde locale
